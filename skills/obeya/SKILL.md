# obeya

A discovery stub, not the guide. Before your first `obeya` command, run `obeya --skill`: it prints the guide for the installed version and names the topics to fetch with `obeya --skill <topic>`.

If `obeya --version` fails, install it with `npm i -g obeya` (Node 22.20 or later); ask the person before installing anything globally.
