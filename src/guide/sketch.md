# Sketch: diverge

Exploring: many directions, quickly, so the person can choose. Read `--skill design` for framing and structure; skip the craft. Draw with `--style sketch`: the server lays down the hand-drawn medium (rough strokes, Excalifont).

- **List the decisions first.** A decision with a visual answer (an editor, a toolbar or none, a save indicator, an icon per page type) gets drawn options; one with no visual answer (what the agent reads) stays a question.
- **3–5 genuinely different directions** for the big one, side by side, labelled A, B, C: different ideas, not variations of one. Don't weld smaller choices into them.
- **One frame per decision**, 2–4 small options each, so the person mixes and matches instead of taking a bundle. Three variants of one icon are fine here. Put the decision's answer slot on its frame, beside the options.
- An overview frame can show the whole with each decision marked ("editor → 02").
- **Black and white.** Colour only to mark something (the one you lean to, a risk).
- Boxes, words, arrows, sticky notes; short labels; no polish, no nudging pixels. Draw the look; flows, routes and data come later unless the decision is about them.
- Assumptions on the board as sticky notes; room for the person to draw.
- One pass over every frame, then one `wait`: they choose. Done when the options are distinct and readable.
